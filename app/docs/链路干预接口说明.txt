链路干预与业务观测接口 v1

范围
16 个逻辑节点、地面站，沿现有固定多跳路径通信。节点 9、13 的业务来自 FPGA 硬件端点，其余节点在 ARM 中维护。
每个 DATA/ACK 都经过已有 FPGA DBPSK、二径信道、AWGN、同步、均衡和纠错链。
本功能改变一条有向上行边，反向边以及其他边保留场景条件。不是射频实验或真实无人机控制。

兼容性与板卡
PL 标识维持 0x000d0003。UART 保留协议 17，新增能力 intervention_schema=1、arm_build=20261021-edge1。
必须加载本目录 ready/swarm_app.elf；使用旧 ARM 固件不能执行链路干预。
ready/system_wrapper.bit 与上一通过版相同。板内已有接收采样与寄存器能力，不需要修改 FPGA。
8 MHz 模型采样率，62.5 MHz PL 时钟；固定 100 ms 通信轮次，每轮 20 个 5 ms 槽。

UART 扩展
LINKOBS 0|1
  选择是否返回同帧观测与被监测边的逐帧诊断。新任务显式设置；普通整机任务关闭额外观测。
NETWATCH 0..31
  指定观测边。干预任务在开始时锁定同一条上行边；此任务 UI 选择范围 0..15。
LINKCOND <40 个十六进制字符>
  小端 5×uint32：操作编号、链路编号、启用覆盖、幅度比例千分数、I/Q 每路噪声 sigma。
  编号递增且不为零；幅度 0..1000；sigma 0..8192；启用值 0 或 1。
  回复 ARM_POLICY_ACCEPTED_AWAITING_PL_FRAME，只证明 ARM 保存规则，不能作为 FPGA 已生效证据。
  effective_round 是 UART 接受指令时下一轮的模型轮次。UART 仅在批次边界处理，不会拆开一笔 DATA/ACK。
  下一次此边发送前，以场景此刻量化的主/回波幅度乘比例，四舍五入写入；噪声取指定值。
  禁用覆盖意味着重新用当前场景条件，并非恢复很久以前保存的寄存器数值。
  不设置接收成功/失败，不修改应用数据，不使用丢包标志制造故障。
NETSTART 清除所有干预规则和操作编号。

观测
NETWORK 增加 observation_schema、condition_serial、edge_trace、edge_trace_overflow、observation。
observation 采自同一个 DATA 事务、在后续 ACK 覆盖硬件之前保存：
  link：有向边编号
  applied[15]：有效、模型毫秒、ACK标志、主径Q15、回波Q15、sigma、主延时、回波额外延时、
               主相位、回波相位、主频偏步长、回波频偏步长、节点可用性标志、噪声状态、距离毫米。
  phy[12]：有效、模型毫秒、ACK标志、FPGA帧代次、捕获、估计频偏、估计信道I/Q、
           定时周期Q16、定时更新数、译码轮数、状态。
  meta[16]：条件编号、业务类型、原始源节点、序号、分片号、生成毫秒、尝试号、状态、
            错误码、纠错前错位数/总位数、纠错后错位数/总位数、CRC寄存器、数据源、帧代次。
  iq：同一符号索引的均衡前/后样点，最多 64 对有符号 I/Q 打包值。未捕获时为空。
  tx_hex、rx_hex：96 字节帧。失败时 rx_hex 为空，不用 TX 补齐。
edge_trace 每行：模型毫秒、条件编号、帧代次、业务类型、源节点、序号、分片号、捕获、CRC通过、尝试号。
  上限 128 帧/批，溢出计数非零会使验收失败。干预任务每批 10 轮（1 模型秒）。
主机独立检查实际读回值、帧身份、CRC 和接收字节；失败记录同样保存。

业务影响与恢复
沿原有路由转发实际接收帧。地面节点记录仅在真正收到心跳后更新。
位置年龄 = 当前模型时间 − 最新收到心跳的源端生成时间，不能用本机 UI 刷新时间。
超过 2 秒判为位置过期。收到旧排队心跳只能更新历史，不能宣称已恢复到新状态。
恢复提示要求收到恢复操作时刻之后生成的心跳，且位置年龄不超过 2 秒。
语音来自节点 1，经 1→2→3→4→地面；视频来自节点 5，经 5→6→7→8→地面。
接收进度由实际分片去重重组统计。最终完整文件逐字节与源文件核对。
这些是已知测试素材，用来验证传输；不是摄像头实时直播。

HTTP API
POST /api/causal/start：link、seed、seconds、config。关闭预设故障及外部注入，便于控制变量。
GET /api/causal/state：当前任务、阶段、最近同帧观测、业务影响、操作记录、最终报告。
POST /api/causal/action：id、kind(change/restore/advance/finish)、window_s、gain_permille、sigma。
  仅当前任务暂停等待时接受；无跨任务操作；参数不合法不改变任务状态。
GET /api/causal/records / record?id=...：只读历史。
POST /api/causal/reproduce：id。验证固件 SHA、计划摘要和观测摘要后，新建实板重算任务。
GET /api/causal/export?id=...：导出计划、事件、观测、原始UART、接收文件、报告和文件SHA。
POST /api/stop：在批次边界停止；暂停中也发送 NETSTOP；部分记录不标为完成。
串口只有一个任务所有者，不允许实验、加载固件、单帧收发互相抢占。

复现口径
重新加载同一配置、种子和业务文件，按保存的模型轮次应用各项操作，执行全部通信轮次。
比较每一轮业务、位置、链路计数、失败帧、寄存器值、实际 IQ 和接收文件摘要。
仅排除与实验功能无关的墙钟时长、FPGA绝对代次及硬件端点诊断累计值。
历史滑块只显示保存数据；“实板重算”才重新使用板卡。
轻度扰动可能被纠错/重传吸收，此时如实显示业务仍正常，不为演示强造失败。
